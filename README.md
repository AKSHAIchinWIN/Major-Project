# 📄 GenAI Resume Analyzer (Using Gemini)

AI-powered resume analyzer that compares resumes with job descriptions using NLP and generates personalized feedback with Gemini AI.

### Tech Stack

Gemini AI • Python • Streamlit • Scikit-Learn • PDFPlumber • ReportLab

### Live Demo

[GenAI resume analyzer link](https://genai-resume-analyzer-yhzaead2rmkfhcibzntbbv.streamlit.app/)


## Features

* 📄 PDF Resume Upload & Parsing
* 📊 Resume Match Score using TF-IDF and Cosine Similarity
* 🤖 AI-Powered Resume Analysis with Gemini AI
* 💡 Personalized Resume Improvement Suggestions
* 🎯 Job Description-Based Resume Evaluation
* 📥 Downloadable PDF Analysis Reports
* ☁️ Cloud Deployment with Streamlit Community Cloud
* 🔍 Automated Resume-Job Compatibility Assessment
* ⚡ Interactive and User-Friendly Web Interface
* 📚 Natural Language Processing (NLP) Powered Analysis
